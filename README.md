# Nagasaki_Soyo_Happy_Birthday
To celebrate Miss Nagasaki Soyo’s birthday, a simple library management system was created using Python and PyQt5,   with an SQLite database for data storage.

The project itself is just a patchwork of beginner Python code, so please don’t expect too much from it. There really aren’t any interesting features in it that you might be hoping for; it was simply created independently by the author out of a passion for learning programming. Although the day it was completed has already passed Miss Soyo’s birthday, I still hope that she can be happy every day and live a meaningful life together with her bandmates.

Happy Birthday Soyorin!!!!!
